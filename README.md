# my portfolio

React + JavaScript + Vite로 만든 한국어 자기소개 사이트입니다.
친구들과 함께하는 게임, 아이디어 떠올리기, 그림·캐릭터 디자인에 대한 관심과 목표를 소개합니다.
파랑·하늘색 디자인을 사용하며 휴대전화와 컴퓨터에서 볼 수 있습니다.
자기소개 메뉴·버튼은 자기소개 페이지(`#/about`)로, 나의 활동 메뉴·버튼은 활동 목록 페이지(`#/portfolio`)로 이동합니다.
각 페이지에서 홈으로 돌아가기와 브라우저 뒤로 가기·새로고침을 사용할 수 있습니다.
활동 카드를 누르면 상세 페이지가 열립니다. 현재 활동 주소는 `#/portfolio/game`입니다.
활동 내용은 `src/App.jsx`의 `projects`에서 수정합니다. 게임명, 활동의 자세한 이야기와 사진은 아직 추가하지 않았습니다.
별명은 정하기 전까지 표시하지 않습니다. 전화번호·주소·생년월일은 넣지 않습니다.

## 내 프로젝트로 시작하기

1. GitHub의 **Use this template → Create a new repository**로 자신의 저장소를 만듭니다.
2. 새로 만든 저장소를 컴퓨터로 복제하고 Visual Studio Code에서 엽니다.
3. 아래 실행 방법에 따라 사이트를 실행합니다.
4. GitHub Copilot과 함께 자기소개, 프로젝트 설명, 색상과 이미지를 자신의 내용으로 바꿉니다.

사진 없이도 사이트를 볼 수 있습니다. 사진이나 작품이 생기면 `public/`에 파일을 넣고 `src/App.jsx`에서 사용하세요.

## 실행하기

1. Node.js 24 LTS를 설치합니다.
2. Visual Studio Code에서 복제한 프로젝트 폴더를 엽니다.
3. 터미널에서 다음 명령을 실행합니다.

```sh
npm install
npm run dev
```

터미널에 표시되는 주소를 브라우저에서 엽니다. 개발 서버는 `Ctrl + C`로 종료합니다.

## 수정할 파일

- `src/App.jsx`: 화면 내용과 React 컴포넌트
- `src/App.css`: 화면 스타일
- `src/index.css`: 전체 공통 스타일
- `public/`: 직접 사용할 이미지 등 정적 파일

파일을 수정하고 저장하면 실행 중인 브라우저에 반영됩니다.

## 확인 명령

```sh
npm run lint
npm run build
```

`npm run build`는 배포용 파일을 `dist` 폴더에 만듭니다.
